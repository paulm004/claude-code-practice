# claude-code-practice

Paul's landing page about what he learned setting up Claude Code at Opt Digital.

## Files
- `index.html`: the whole page, with its CSS in a `<style>` block.
- `images/`: images used by the page (the proof screenshot goes here).

## Rules
- Plain HTML and CSS only. No frameworks, no build step, no npm, no JavaScript libraries.
- The page must read well on a phone and on a laptop.
- This repo is public: no secrets, API keys or private company information.

## Preview
Open `index.html` in a browser by double-clicking it, or run `start index.html` in
PowerShell. To check phone width, use the browser's DevTools device mode (F12, then
Ctrl+Shift+M).

## Deploy
Vercel deploys the site automatically from the `main` branch. Work on a branch and open a
pull request. Will reviews it and merges it into `main`.
